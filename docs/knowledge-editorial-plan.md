# 具身智能知识分享：首季编辑方案

制定日期：2026-11-10。第一篇在本周发布，后续以每周一篇为节奏。下面的周次是选题顺序，可根据读者问题调整。

## 定位与阅读路径

系列名称：具身智能，从基础到实践。

服务有理工背景的学生、工程师和机器人研发人员。正文建立共同语言，技术补充解释接口与假设，原始资料供进一步研究。第一季以机器人操作为主要例子，同时让读者看清其与导航、运动控制的关系。

主线：理解闭环 → 理解数据与动作 → 理解策略学习 → 判断系统表现。

每篇形成一个可独立分享的回答，同时连接前置概念和下一篇。课程化的积累来自稳定结构、术语、练习和可复用图示。数采设备、团队数据与真机实验在出现具体素材后再进入选题。

## 一篇文章的稳定结构

1. 具体问题：以任务、困惑或现象开头。
2. 核心结论：说明这篇文章要帮助读者建立的认识。
3. 概念与图示：用一个贯穿例子讲清关键关系。
4. 技术补充：解释接口、变量、时序或实验设置。
5. 开源阅读：2–5 个具体章节或实现入口，各写一句阅读目的。
6. 思考或练习：让读者能检查自己是否理解。
7. 前后连接：指出前置概念和下一步问题。

首篇覆盖基础地图，后续单篇围绕一个问题逐步深入。专业读者的价值来自概念精度、接口分析、原始来源和真实复现。

## 每周生产节奏

- 选题：从路线图和读者问题中确定本周的一个问题。
- 调研：阅读教材、作者论文、官方文档与实现，记录主张对应的来源。
- 写作：AI 协助结构、初稿、概念图和语言整理；编辑校对技术关系、术语与引用。
- 审阅：检查读者是否能复述核心结论，示例是否支持该结论。
- 发布：检查桌面、手机、目录、外链与首页入口；发布文章。
- 回流：整理讨论中的新问题，补充勘误或纳入后续选题。

建议准备两篇选题储备，始终让下一篇有提纲和主要资料。每四篇回看一次：读者理解最卡在哪里、哪类内容被引用、练习是否能完成。
